# 🏦 Fintech Wallet - Full Stack Application

Welcome to the **Fintech Wallet** repository. This is a complete, full-stack digital banking solution that provides users with a secure, seamless, and interactive platform to manage their finances, execute transactions, and receive AI-driven financial insights.

## 🚀 Tech Stack

### Frontend
* **Framework:** Next.js (App Router)
* **Library:** React
* **Styling:** Tailwind CSS
* **Language:** TypeScript
* **State Management:** Context API

### Backend
* **Framework:** Java, Spring Boot (Spring Web, Spring Data JPA, Spring Security)
* **Database:** PostgreSQL / MySQL
* **Authentication:** JWT (JSON Web Tokens)
* **AI Integration:** Spring AI / SDK Integration
* **Build Tool:** Maven

## ✨ Key Features

* **🔐 Secure Authentication:** JWT-based login and registration with automated session hydration, role-based access control, and robust logout handling.
* **💸 Smart Transactions & OTP:** Securely deposit, withdraw, and transfer funds. Includes a dynamic OTP verification system for high-value transactions (e.g., exceeding 10,000 BDT).
* **🤖 AI Financial Insights:** An interactive chat widget in the frontend connected to the Spring Boot AI backend, allowing users to ask custom questions and receive dynamic, intelligent advice regarding their wallet and spending habits.
* **👤 KYC Verification:** Streamlined identity verification pipeline where users submit specific required details (DOB, Address, etc.) to the backend for account approval.
* **🔔 Real-Time Notifications:** Dynamic bell-icon notification system to track account activities and transaction statuses.
* **📊 Interactive Dashboard:** View real-time wallet balances, account limits, and detailed transaction histories.

## 🛠️ Prerequisites
* **Node.js** (v18 or higher)
* **Java** (v17 or higher)
* **Maven**
* **PostgreSQL** or **MySQL** Server
