# 💳 Fintech Wallet - Frontend

Welcome to the frontend repository of the **Fintech Wallet** application. Built with modern web technologies, this interface provides users with a seamless, secure, and interactive digital banking experience.

## 🚀 Tech Stack
* **Framework:** Next.js (App Router)
* **Library:** React
* **Styling:** Tailwind CSS
* **Language:** TypeScript
* **State Management & Auth:** Context API / JWT (JSON Web Tokens)

## ✨ Key Features
* **Secure Authentication:** Robust login and registration flow with automatic session management and hydration handling.
* **Interactive Dashboard:** View real-time wallet balances, account status, and dynamic transaction history.
* **Fund Transfers & OTP:** Send money securely, featuring a conditional OTP verification modal for high-value transactions (over 10,000 BDT).
* **KYC Verification:** Streamlined form for submitting exact identity details required by the Spring Boot backend.
* **AI Financial Insights:** An interactive AI chat widget that provides personalized spending advice and answers wallet-related queries.
* **Notification System:** Real-time bell icon alerts for account activities and transaction updates.
